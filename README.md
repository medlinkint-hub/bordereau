# HWA Bordereau Builder

Monthly bordereaux and KPI/SLA reports for each insurer, generated in the browser from the HWA case export.

- Open `index.html` (or the GitHub Pages address) and set a PIN on first use.
- Case files are read only in the browser; nothing is uploaded or stored on a server.
- Insurer profiles live in the browser — use Settings → Export backup to move them to another computer.
